# 🛰 ORBITAL

Station de mini-jeux multijoueurs entre potes.

## Télécharger

Va dans **[Releases](../../releases/latest)** et prends le fichier pour ta machine :

| Système | Fichier |
|---|---|
| Mac Apple Silicon (M1, M2, M3…) | `ORBITAL-x.y.z-arm64.dmg` |
| Mac Intel | `ORBITAL-x.y.z-x64.dmg` |
| Windows | `ORBITAL-Setup-x.y.z.exe` |

L'app se met ensuite à jour toute seule.

## Première installation

L'app n'est pas signée par Apple ou Microsoft, il faut donc l'autoriser **une seule fois** :

**Mac** — ouvre le `.dmg`, glisse ORBITAL dans **Applications**, lance-le. Si macOS le bloque :
Réglages Système → Confidentialité et sécurité → **Ouvrir quand même**.
ORBITAL doit rester dans Applications pour recevoir les mises à jour.

**Windows** — si l'écran « Windows a protégé votre ordinateur » apparaît :
**Informations complémentaires** → **Exécuter quand même**.
